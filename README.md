## CSE 330 (Operating Systems) 

This is a clone of the public repository for Operating Systems taught in Spring 2024 by Adil Ahmad.

### Branch: The Block Abstraction

In this project, I was tasked with writing a kernel module that allows a user program to directly access a virtual USB storage device using the block abstraction.
Your kernel module supports both read and write operations of different block sizes, and at different offsets.
